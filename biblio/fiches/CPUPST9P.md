# Quick Annotator: an open-source digital pathology based rapid image annotation tool

**Auteurs** : Runtian Miao, Robert Toth, Yu Zhou, Anant Madabhushi, Andrew Janowczyk
**Année** : 2021
**DOI** : 10.1002/cjp2.229

## Résumé

Image based biomarker discovery typically requires an accurate segmentation of histologic structures (e.g., cell nuclei, tubules, epithelial regions) in digital pathology Whole Slide Images (WSI). Unfortunately, annotating each structure of interest is laborious and often intractable even in moderately sized cohorts. Here, we present an open-source tool, Quick Annotator (QA), designed to improve annotation efficiency of histologic structures by orders of magnitude. While the user annotates regions of interest (ROI) via an intuitive web interface, a deep learning (DL) model is concurrently optimized using these annotations and applied to the ROI. The user iteratively reviews DL results to either (a) accept accurately annotated regions, or (b) correct erroneously segmented structures to improve subsequent model suggestions, before transitioning to other ROIs. ## Conclusions

Quick Annotator est un outil d'annotation d'images à haut débit, publié en open-source pour révision, commentaire et usage par la communauté QA démontre des améliorations significatives de l'efficacité d'annotation sans sacrifier la fidélité des annotations QA peut parfois surpasser ce qu'un humain peut accomplir sans outils assistés par ordinateur Les versions futures de QA viseront à supporter l'annotation directe de WSI complètes et à réduire davantage la latence perçue de l'entraînement DL par l'utilisateur
