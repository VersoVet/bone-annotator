## Résumé

Object detection (OD) technology, which identifies and classifies objects in images and videos, has been widely adopted across various fields. However, implementing OD faces challenges, including image preprocessing, labeling, model development, and deployment. To streamline these processes, we developed a Python-based software Ladder (Labeling and Detection Deployment for Entity Recognition). Ladder features a user-friendly graphic interface (GUI) that facilitates efficient labeling of training datasets, detection of new images, and model training. The software utilizes an interactive recurrent framework that begins with predictions from a pre-trained model for initial image labeling. Users can then add human labels, and these newly labeled images can be incorporated into the training data to retrain the model. ## Conclusions

Ladder est un outil efficace pour développer des systèmes de détection d'objets (OD) via un flux de travail intégré d'annotation, d'entraînement et de déploiement, démontré par une étude de cas sur la détection du riz brisé L'affinement progressif des données d'entraînement à travers différents stades améliore la capacité du modèle à reconnaître le riz brisé Ladder offre une boucle itérative annotation-entraînement-prédiction ayant le potentiel de simplifier l'étiquetage d'images, la détection d'objets et le ré-entraînement de modèles Ladder a le potentiel de supporter un flux de travail unifié pour des images à grande échelle avec une forte densité de petits objets
