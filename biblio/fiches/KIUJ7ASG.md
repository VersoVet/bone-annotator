# TreeJ: an ImageJ plugin for interactive cell lineage reconstruction from static images

**Auteurs** : Elise Laruelle, Jean-Christophe Palauqui, Philippe Andrey, Alain Trubuil
**Année** : 2023
**DOI** : 10.1186/s13007-023-01106-x

## Résumé

Abstract Background With the emergence of deep-learning methods, tools are needed to capture and standardize image annotations made by experimentalists. In developmental biology, cell lineages are generally reconstructed from time-lapse data. However, some tissues need to be fixed to be accessible or to improve the staining. In this case, classical software do not offer the possibility of generating any lineage. Because of their rigid cell walls, plants present the advantage of keeping traces of the cell division history over successive generations in the cell patterns. To record this information despite having only a static image, dedicated tools are required. Results We developed an interface to assist users in the building and editing of a lineage tree from a 3D labeled image. Each cell within the tree can be tagged.
