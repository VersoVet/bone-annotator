## Résumé

Mobile eye tracking is an important tool in psychology and human-centered interaction design for understanding how people process visual scenes and user interfaces. However, analyzing recordings from head-mounted eye trackers, which typically include an egocentric video of the scene and a gaze signal, is a time-consuming and largely manual process. To address this challenge, we develop eyeNotate, a web-based annotation tool that enables semi-automatic data annotation and learns to improve from corrective user feedback. Users can manually map fixation events to areas of interest (AOIs) in a video-editing-style interface (baseline version). Further, our tool can generate fixation-to-AOI mapping suggestions based on a few-shot image classification model (IML-support version). We conduct an expert study with trained annotators (n = 3) to compare the baseline and IML-support versions. ## Conclusions

eyeNotate est un outil d'annotation interactive pour les données d'eye tracking mobile basé sur la classification d'images few-shot (FSL) Le case study a confirmé que eyeNotate permet efficacement le mapping fixation-vers-AOI: les utilisateurs ont apprécié la fonctionnalité de base et le design d'interaction, et la validité et fiabilité des annotations des utilisateurs étaient élevées Fournir des suggestions de labels AOI dans la version avec support IML n'a pas augmenté l'efficacité, probablement à cause de problèmes de performance du modèle qui ont conduit à une faible confiance chez les annotateurs entraînés Les résultats suggèrent que le FSL présente un grand potentiel pour initier l'annotation interactive de données Les temps de complétion des tâches étaient globalement bas, de 1.11 s par annotation (meilleur cas) à 2.41 s (pire cas) Les participants ont identifié la performance limitée du modèle comme le principal facteur limitant, en particulier les problèmes avec des AOI d'apparence similaire Cette limitation a été confirmée par l'expérience de machine learning post hoc
